# Data Retention (PROPOSED defaults — owner must confirm)
| Data | Retention |
|---|---|
| Server settings, subscription records | While the bot is in the server + 90 days after removal, then deleted |
| Moderation cases / warnings | 12 months after creation or until server deletion request |
| Tickets and transcripts | 90 days after close (configurable per server) |
| XP / economy / transactions | While in server + 90 days after removal |
| Orders and payment records | 7 years for accounting if required locally (confirm with an accountant) |
| Audit logs | 24 months |
| Application logs | 30 days |
| Database backups | 14 daily / 8 weekly / 6 monthly; deleted data leaves backups within 6 months |
Deletion requests: verify the requester (server owner), delete within 30 days, record the request, keep only legally required records.
